## 🛠️ How to Record This in 3 Minutes on Mac

1. **Start the local server**:
   ```bash
   python3 server.py 8080
   ```
2. **Open browser**: Go to `http://localhost:8080` in Chrome/Safari and make it full screen.
3. **Start Screen Recording**: Press `Cmd + Shift + 5`, select the browser window, and click **Record**.
4. **Read or Paste the Voiceover**: Read along with the timestamped script above, clicking each preset button as indicated.
5. **AI Voiceover Option**: You can copy-paste the voiceover lines into [ElevenLabs.io](https://elevenlabs.io) or [Clipchamp](https://clipchamp.com) to generate a studio-grade AI narrator voice for free!
